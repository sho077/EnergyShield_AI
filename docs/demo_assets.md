# Demo Screenshot / Evidence Checklist

Capture these from `streamlit run dashboard/app.py` for the video and
presentation. Use the same browser window size for all captures so the
dashboard looks visually consistent across the deck and video.

1. **Main Command Center** — Screen 1, top of page: header badge, KPI rows,
   and the four-layer "What the system knows today" panel all visible.
2. **Full India network map** — Screen 1, map section, all five layer
   filters checked.
3. **Jamnagar detail** — Screen 1, the R022/R023 hero cards, scrolled so
   both cards and the caveat note are visible.
4. **Network resilience table** — Screen 2, the ranked refinery connectivity
   table with Model Status / Evidence Status columns visible.
5. **Hormuz scenario result** — Screen 5, "Hormuz Disruption" selected, Step
   3 (Exposure) and Step 4 (Alternatives) visible.
6. **Data Trust page** — Screen 6, source registry table plus the "Why trust
   this?" panel.
7. **AI roadmap** — Screen 7, CURRENT/NEXT/LATER sections with at least one
   NEXT agent expander open.

Keep filenames consistent, e.g. `01_command_center.png` … `07_ai_roadmap.png`,
so they can be dropped into the deck and video timeline in order.
